# guest-agent — гостьовий агент

Привілейований системний застосунок на Kotlin (підпис platform key) + init-скрипти (ТЗ, розділ 5.1).

Обов'язки: буфер обміну, перенесення файлів, правила iptables (режим A: блок вихідного UDP крім DNS, IPv6 вимкнено), VpnService + tun2socks (режим B).

Статус: не розпочато; потрібен у фазі 1. Gradle-проєкт з'явиться разом з першим образом.
