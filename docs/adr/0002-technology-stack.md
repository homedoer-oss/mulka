# ADR-0002: Стек технологій

- Статус: Прийнято
- Дата: 2026-11-25

## Контекст

Продукт — лише для Windows x64 у v1.0. Даємон, UI і CLI ділять моделі й gRPC-контракти. Шлюз запускається на кожен інстанс (до 10 копій) і працює з недовіреним мережевим трафіком.

## Рішення

- Даємон, UI, CLI — C# на .NET 10 LTS (підтримка до листопада 2028); UI — WPF + CommunityToolkit.Mvvm.
- Net Gateway — Rust (tokio), окремий процес на інстанс.
- Гостьовий агент — Kotlin, системний застосунок.
- Сховище — SQLite (WAL) для реєстру, JSON для конфігів інстансів.

## Наслідки

- Один репозиторій, дві системи збірки (`dotnet`, `cargo`) плюс Gradle для агента і окрема збірка емулятора.
- Шлюз займає ~5–10 МБ RAM на інстанс, що тримає NFR-04 (≤ 150 МБ на менеджер).
- .NET 8 не розглядали: його підтримка закінчилась 10.11.2026.

## Розглянуті варіанти

Avalonia замість WPF — якщо з'явиться кросплатформа. Шлюз на C# — простіше, але більший слід пам'яті на 10 процесах.
