# ADR-0004: Адреси і порти Net Gateway

- Статус: Прийнято
- Дата: 2026-11-25

## Контекст

Емулятор з'єднується з шлюзом з боку хоста (режим A, `-http-proxy`), а гість у режимі B — через `10.0.2.2`, який у мережі емулятора веде на `127.0.0.1` хоста, а не на інші loopback-адреси. DNS-сервер має фіксований порт 53, тому кожному інстансу потрібна власна адреса для DNS.

## Рішення

Для інстансу N (N = 0–9):

| Вхід | Адреса |
| --- | --- |
| HTTP CONNECT | `127.0.0.1:(18080 + N)` |
| SOCKS5 | `127.0.0.1:(11080 + N)`; з гостя `10.0.2.2:(11080 + N)` |
| DNS | `127.0.1.(N+1):53` |

SOCKS5-вхід вимагає логіна і пароля, унікальних для інстансу; даємон передає їх агенту при старті.

## Наслідки

- Через `10.0.2.2` гість бачить увесь loopback хоста. Авторизація на SOCKS5 не дає йому вийти через шлюз чужого інстансу. Інші локальні сервіси (даємон, gRPC емулятора) так само мають вимагати токен.
- `127.0.1.(N+1)` уникає адреси `127.0.1.0`.
