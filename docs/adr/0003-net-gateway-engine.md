# ADR-0003: Рушій Net Gateway

- Статус: Запропоновано (рішення — до кінця фази 0)
- Дата: 2026-11-25

## Контекст

Шлюзу потрібні: вхід HTTP CONNECT і SOCKS5 (з авторизацією), DNS-сервер, що резолвить через proxy, upstream HTTP/HTTPS/SOCKS5/SOCKS5h з авторизацією, UDP ASSOCIATE, гаряча зміна upstream і керування через named pipe. Прямого маршруту бути не повинно (ТЗ, розділ 6).

## Варіанти

| | Власний шлюз на Rust (tokio) | sing-box як окремий процес |
| --- | --- | --- |
| Ліцензія | Своя | GPL-3.0: лише окремий бінарник, публікуємо вихідники |
| Обсяг роботи | Більший: протоколи, DNS, UDP | Менший: протоколи готові |
| Контроль kill switch і керування | Повний | Через конфіг і API sing-box |
| v1.1 (Shadowsocks, ланцюжки) | Писати самим | Вже є |

## Що перевірити у фазі 0

- [ ] Прототип власного шлюзу: HTTP CONNECT → SOCKS5 upstream з авторизацією, DNS через proxy
- [ ] sing-box: гаряча зміна upstream без розриву, керування з даємона, слід пам'яті на 10 процесах
- [ ] Обидва: тест витоків (pcap) на одному інстансі

## Рішення

Буде заповнено за результатами перевірки.
