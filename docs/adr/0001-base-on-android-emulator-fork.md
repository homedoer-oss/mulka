# ADR-0001: Основа — форк Android Emulator + власні AOSP-образи

- Статус: Прийнято
- Дата: 2026-11-25

## Контекст

Потрібно запускати до 10 ізольованих інстансів Android 9–16 на Windows 10/11 з апаратною віртуалізацією, GPU-прискоренням і снапшотами. Писати гіпервізор і GPU-стек з нуля — роки роботи.

## Рішення

Беремо форк AOSP `platform/external/qemu`, зібраний з вихідників під Windows, і власні AOSP-образи (`userdebug`, без GMS). Гіпервізор — WHPX за замовчуванням, AEHD як альтернатива там, де Hyper-V вимкнено.

## Наслідки

- Отримуємо WHPX/AEHD, gfxstream, снапшоти і gRPC-API без власної розробки.
- Збірка під Windows складна; її перевіряє фаза 0. Якщо PoC не пройде за 3 тижні — переходимо на резервний варіант (чистий QEMU + Android-x86) з втратою ~6 тижнів.
- Треба фіксувати коміт upstream і ребейзитись раз на 6 місяців (NFR-12).
- QEMU-частини — GPL-2.0: вихідний код форку публікуємо.

## Розглянуті варіанти

Чистий QEMU + Android-x86/BlissOS (резерв), Cuttlefish у WSL2 (дослідити для v2), VirtualBox + Android-x86 (відхилено), Windows Subsystem for Android (підтримку припинено). Деталі — ТЗ, розділ 2.
