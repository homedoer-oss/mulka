# gateway — Net Gateway

Окремий процес на кожен інстанс; весь трафік гостя йде лише через нього (ТЗ, розділ 6).

Входи інстансу N (ТЗ, розділ 5.2):

| Вхід | Адреса |
| --- | --- |
| HTTP CONNECT (режим A) | `127.0.0.1:(18080 + N)` |
| SOCKS5 (режим B), з авторизацією на інстанс | `127.0.0.1:(11080 + N)` |
| DNS | `127.0.1.(N+1):53` |

Керування від даємона — named pipe. Прямого маршруту немає: якщо upstream недоступний, з'єднання відхиляється.

Статус: заготовка. Чи писати власний шлюз на Rust, чи взяти sing-box як окремий процес, вирішується у фазі 0 — див. [ADR-0003](../docs/adr/0003-net-gateway-engine.md).
